# Aniket Bembale — Portfolio

A single-page React portfolio for Aniket Bembale (AI Engineer), built with Vite.

## Sections
- Hero + quick stats
- About
- Skills & technologies
- Experience (timeline)
- Featured projects
- Research & publications
- Certifications & education
- GitHub repositories
- Contact

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:5173).

## Build for production

```bash
npm run build      # outputs to dist/
npm run preview    # preview the production build
```

## Deploy
The `dist/` folder is static — deploy it to Vercel, Netlify, GitHub Pages,
Cloudflare Pages, or AWS S3 + CloudFront.

## Edit your content
All text lives in `src/data.js` — update it there and everything re-renders.
